#  Team Task Manager (Full-Stack)

A professional task management application featuring role-based access control (RBAC), designed for tech startups and small teams.

##  Features
- **Secure Authentication:** JWT-based login and signup.
- **Admin Dashboard:** Create projects and assign tasks to specific team members.
- **Member Dashboard:** View personal tasks and track progress.
- **Stealth Tech UI:** Minimalist pitch-black aesthetic with metallic gold accents.

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, Vite.
- **Backend:** Java 21, Spring Boot 3, Spring Security (JWT).
- **Database:** MySQL.
- **Deployment:** Railway.

##  Setup Instructions
1. **Backend:** Configure `application.properties` and run `.\mvnw.cmd spring-boot:run`.
2. **Frontend:** Run `npm install` followed by `npm run dev`.
